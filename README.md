# Aesthetic Business Consultancy Landing Page

A static landing-page demo developed by Infinex Loop for a business consultancy serving hospitality and other commercial establishments. It demonstrates a responsive presentation of the consultancy’s services and approach, with direct email and phone actions.

The site uses HTML, CSS, vanilla JavaScript, and GSAP. The hero cycles through Plan, Design, Launch, and Grow, with a native animation fallback and a static reduced-motion state. The page also includes industries served, advisory capabilities, expertise, the consulting approach, and contact details. **YOUR BRAND** is placeholder branding for the demo.

## Run locally

Download or clone the repository and open `index.html` in a browser. No installation or build is required. An internet connection loads GSAP and the web fonts. The page includes fallback typography and animation for offline use.

## Project structure

- `index.html` contains the page, styles, scripts, and inline artwork.
- `README.md` describes the demo and how to preview it.
- `.gitignore` excludes local development materials and generated files.
